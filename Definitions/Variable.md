## Plain English Definition
A variable is one measured attribute recorded for each observation, such as age, year, or education. In the textbook notation, variables are indexed by $j=1,\dots,p$.

## Formal Definition
$$
j \in \{1,2,\dots,p\}
$$
| Symbol | Meaning |
|---|---|
| $j$ | Index for a variable |
| $p$ | Total number of variables |

## Intuitive Analogy
A variable is like one column in a spreadsheet. If each row is a person, then columns such as age, income, and education are the different variables recorded about that person.

## When to Use It
- ✅ When describing the features available to explain or predict an outcome.

## When It Breaks Down
- ❌ When columns are inconsistently defined, measured on incompatible scales without adjustment, or contain mixed meanings.
