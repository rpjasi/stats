## Plain English Definition
Classification is a supervised learning problem in which the response is qualitative or categorical. The aim is to assign each observation to one of a fixed set of classes, such as `Up` or `Down`.

## Formal Definition
$$
Y \in \{1,2,\dots,K\}
$$
| Symbol | Meaning |
|---|---|
| $Y$ | Categorical response variable |
| $K$ | Number of possible classes |

## Intuitive Analogy
Classification is like sorting incoming emails into folders such as personal, work, and spam. You are not predicting a number; you are deciding which labeled bucket each new item belongs in.

## When to Use It
- ✅ When the response is a category, label, or discrete class.

## When It Breaks Down
- ❌ When the outcome is naturally numeric or when class labels are ambiguous, heavily imbalanced, or poorly defined.
