## Plain English Definition
Supervised learning uses input variables together with a known output variable. The goal is to learn a rule that predicts or estimates the output from the inputs.

## Formal Definition
$$
\{(x_1,y_1), (x_2,y_2), \dots, (x_n,y_n)\}
$$
| Symbol | Meaning |
|---|---|
| $x_i$ | Input features for observation $i$ |
| $y_i$ | Observed response for observation $i$ |
| $n$ | Number of observations |

## Intuitive Analogy
Supervised learning is like studying with an answer key. You see examples of questions and their correct answers, and you try to learn the pattern well enough to answer new questions you have not seen before.

## When to Use It
- ✅ When you have labeled examples and want to predict a future or unseen outcome.

## When It Breaks Down
- ❌ When the labels are missing, unreliable, or no longer representative of the future cases you care about.
